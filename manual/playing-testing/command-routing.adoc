=== Command Routing

Input passes from the Telnet session to the hosted instance and the profile's
LPC command behavior. The configured `transport.control_prefix` reserves an
escaped namespace for connection controls; its default is `//`.

* `//help` and `//quit` are transport controls in profiles using the default transport prefix.
* `look` and movement verbs go to the mudlib after login.
* Ordinary single-slash commands remain available to mudlib code.
* `load`, `inspect`, and `reload` are local admin-shell operations, not a remote
  administration protocol.

If a command is unrecognized, first identify which of these contexts received it.
Then check the active profile's lifecycle mappings and command registration.

=== Layout

A useful source layout separates authored content, host configuration, and
writable state. This is an illustrative convention, not a required game:

[source,text]
----
<content-root>/
  source/           LPC source, headers, and authored data
  jvmud/            manifest and host-facing adapters
  <state-area>/     profile-selected writable data
----

`mudlib_root` selects the actual source root. If the manifest lives in `jvmud/`,
`mudlib_root = ../source` resolves from that directory. Inspect persistence code
before choosing, moving, or cleaning state paths; not every store uses a sibling
state directory.

Supply peer manifests to `scripts/jvmud-start <manifest> <manifest> ...`.
The engine offers them in a connection menu. Each must have a unique game id.
`mount.*` declarations and world-hopping are unsupported. No manifest owns or
implicitly discovers other worlds.

Small Mercies follows this separation under `mudlibs/smallmercies/`. Its guest
characters are transient; it does not demonstrate durable account storage.

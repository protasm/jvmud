=== Testing And Verification

Run the repository baseline from its root:

[source,shell]
----
mvn test
----

For a targeted change, select the relevant JUnit class, for example:

[source,shell]
----
mvn -Dtest=MudlibAdminCommandSessionTest,EngineArchitectureTest test
----

Some integration checks require an external database and configured password
environment variable. A missing prerequisite is an incomplete integration check,
not a passing compatibility result. Read the failing test and profile before
classifying it as a Java regression.

Use `target/surefire-reports/` for test outcomes. Informational compatibility
reports and full preload scans answer different questions from assertions and
live player tests. Shared scan tooling is `scripts/scan-mudlib-preload-compile.sh`;
profile wrappers remain under the owning mudlib's `jvmud/` directory.

For runtime changes, restart the affected profile and replay the relevant player
route. For documentation-only edits, regenerate outputs and check local links,
anchors, commands against source, and PDF layout. See <<_documentation_generation>>.

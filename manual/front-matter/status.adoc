JVMud is an LPC/LPMud engine for the JVM. This manual explains how
to understand its design, run a local world, inspect LPC objects, and develop
mudlib content against the current repository.

The documented version is {revnumber}. The platform provides a compiler, world
model, hosted instances, Telnet sessions, storage adapters, and an admin shell.
Compatibility is incremental; a successful build or preload scan does not prove
complete gameplay or production readiness.

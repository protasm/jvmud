=== Core packages and repository tour

[[_repository_tour]]
All Java package names below begin with `io.github.protasm.jvmud`.

[cols="1,3",options="header"]
|===
|Package |Responsibility and starting points
|`language` |LPC compilation and runtime support. Start with `JVMudCompiler`,
`pipeline`, and `exec.LPCRuntime`. `runtime` supports generated bytecode;
`diagnostics` contains standalone compilation checks.
|`execution` |`application` owns startup, worker supervision, and updates;
`model` defines worlds, identities, time, and mudlib contracts;
`instance` assembles and runs one mudlib.
|`communication` |`transport` owns connection mechanics, `admin` interprets
administrative commands, and `console` supplies the terminal client.
`protocol` and `output` handle structured messages and text presentation.
|`storage` |Durable adapters under `filesystem`, `jdbc`, and `admin`.
|===

`src/main/java/` contains these packages; `src/test/java/` mirrors them.
`mudlibs/<name>/source/` contains LPC content, and `mudlibs/<name>/jvmud/`
contains manifests, adapters, and profile-specific scripts. Inspect the selected
profile before assuming all mudlibs have the same storage layout.

`manual/` contains editable AsciiDoc; `docs/` contains the site, generated manual,
and API. Shared tools live in `scripts/`. `pom.xml` defines dependencies and
build profiles. See <<_documentation_generation>> before editing generated pages.

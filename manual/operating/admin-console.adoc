=== Administration consoles

The engine starts independently of mudlibs. Its player port presents a public
menu; its TLS admin port manages mudlib lifecycles and engine-owned administrator
grant records. Each mudlib runs in a separate worker JVM with its own player/admin
port pair. Mudlib administration operates on that worker's live objects.

Bootstrap locally as the engine's OS account:

[source,shell]
----
scripts/jvmud-start
# In another terminal:
scripts/jvmud-console --socket ~/.jvmud/engine-4000/engine.sock
----

[source,text]
----
admin-create operator
grant operator engine
start /absolute/path/to/mudlib/jvmud/mudlib.config 4100 4101
status
----

Store the issued random token securely; it is displayed only once. The engine
stores its hash and grants. Remote connections require the certificate fingerprint
printed by the engine, obtained through a trusted channel:

[source,shell]
----
scripts/jvmud-console --host server.example --port 4001 --user operator --fingerprint <SHA-256>
----

The console prompts for the token. Use `--token-file <private-file>` when no
interactive terminal is available. Engine grants include all mudlibs;
`grant <name> mudlib:<id>` limits an administrator to one mudlib. Grants are
independent of OS accounts, player accounts and in-game wizard privileges.

Connect to a mudlib's admin port for `objects`, `inspect`, `call`, `reload`, and
other mudlib commands. `quit` disconnects only the console. `stop` and `restart`
are engine commands; `shutdown` stops the engine and all workers. A worker crash
closes its connections while leaving the engine and other mudlibs running.

The private engine state defaults to `~/.jvmud/engine-<player-port>` and contains
its recovery socket, registry, TLS identity and bounded worker logs. Override it
with `--state-dir`. Keep it outside mudlib trees. macOS requires `sandbox-exec`;
Linux requires bubblewrap and user namespaces. Sandbox startup fails closed.

See the repository's `docs/ENGINE-ADMINISTRATION.md` for isolation limits, timeout
behavior, certificate management and the complete operating workflow.

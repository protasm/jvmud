=== Running JVMud

For a ready-to-run example, use <<small-mercies>>. To host your own content,
select a JVMud-compatible LPC source tree and its manifest. JVMud is the
host; it does not choose game content implicitly. The manifest must describe
real source files, including an initial Place and the profile's player behavior.
Small Mercies is the bundled teaching example; the same host contract applies
to other compatible content.

In a terminal at the repository root:

[source,shell]
----
scripts/jvmud-start <mudlib-config-file>
----

Replace `<mudlib-config-file>` with the absolute path to your manifest, or a path
relative to the repository root. Do not type the angle brackets. The script
compiles Java, resolves the dependency classpath, and runs the Telnet server in
the foreground. Wait for the preload summary followed by
`JVMud engine listening on 127.0.0.1:4000` before connecting.

The launcher defaults to loopback port 4000. Use `--bind 0.0.0.0 --port 4000`
to accept incoming connections on all IPv4 interfaces, or choose a specific
local address and a different port. Clients use the server's actual address;
allow the selected TCP port through applicable firewalls and router forwarding.
Each listener needs an available address/port pair. Mounted profiles, if declared,
must also be present and valid. See <<_configuration_reference>> for manifest keys.

To capture detailed startup failures:

[source,shell]
----
scripts/jvmud-start --trace-startup-loads <mudlib-config-file> > target/startup.log 2>&1
----

This still runs in the foreground. Inspect the log from another terminal and
stop with Ctrl+C. Trace output can be large; begin with the preload summary and
first failure. To see launch syntax, use `scripts/jvmud-start --help`.

Ctrl+C runs the server's shutdown path. Persistence is profile-specific; shutting
down does not promise a snapshot of every loaded object's state. Add `--admin-port 4100` to enable the authenticated local admin listener, then
connect with `scripts/jvmud-cli --port 4100`. The CLI controls this live primary
world; its port is separate from the player port.

==== Offer several mudlibs

Pass each manifest or mudlib name as a separate argument:

[source,sh]
----
scripts/jvmud-start smallmercies lp245
----

The engine presents a selection menu before login, including for a single
mudlib. Enter the menu number or game id. Mudlibs are peers; reconnect to choose
another. Each instance has its own clock, configured by `temporal_tick_interval`,
and serializes input and scheduled work on its own execution thread.

When enabling administration for several mudlibs, use `--admin-game <game-id>`
to choose the mudlib served by that admin endpoint.

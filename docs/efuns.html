Engine functions

Efuns

Efuns are the LPC-facing entry points that let compiled mudlib objects talk to JVMud runtime behavior.

Compatibility Layer

JVMud can expose legacy LPC names while translating them toward engine-native operations: output delivery, current execution context, object calls, movement, inventory traversal, perception, and scheduling.

Design Bias

Efuns should keep current LPC content usable without making old driver concepts the engine's ontology. Compatibility belongs at the boundary.

Current Core Efuns

This is the core set currently registered by JVMud's engine efun registry. Overloaded efuns are listed once per supported signature.

Text And Output

Signature Current behavior
void jvmud_write(mixed message) Writes text to the active output sink.
void jvmud_send_to_entity(object target, mixed message) Delivers text to a target entity through runtime output routing.
void jvmud_emit_perceivable(mixed emitter, mixed message) Emits a perceivable message from an entity to suitably perceptive entities at its location.
void jvmud_emit_perceivable_at(mixed location, mixed message) Emits a perceivable message at an explicit location for compatibility shims.

Execution Context And Sessions

Signature Current behavior
object jvmud_current_entity() Returns the current LPC object in the active runtime context.
object jvmud_current_actor() Returns the current command Persona, falling back to the current object.
string jvmud_current_verb() Returns the verb being dispatched for the active command.
array jvmud_users() Returns the runtime's currently bound session personas.
int jvmud_query_idle(mixed user) Reports idle time for a runtime session/user target.
mixed jvmud_query_ip_number(mixed user) Reports the remote address associated with a session/user target when known.
void jvmud_capture_session_input(string method, int noecho) Captures the next line of session input for a mudlib method.

Entities, Locations, And Containment

Signature Current behavior
string jvmud_entity_id(mixed entity) Returns the registered runtime entity id.
mixed jvmud_invoke_entity(mixed target, string method) Invokes a method on an entity or path-resolved shared entity.
mixed jvmud_invoke_entity(mixed target, string method, mixed arg) Invokes a method with one argument on an entity or path-resolved shared entity.
object jvmud_spawn_entity(string path) Compiles if needed and creates a new runtime clone.
void jvmud_move_entity(mixed entity, mixed destination) Moves an entity into a location, container entity, or path-resolved destination.
object jvmud_find_entity(string id) Finds an entity by identifier using the current context.
object jvmud_find_entity(mixed id, mixed location) Finds an entity by identifier in a supplied location or container.
object jvmud_first_entity_at(mixed location) Starts entity traversal for a location or container.
object jvmud_next_entity_at(mixed entity) Continues traversal from a previous entity at the same location.
object jvmud_entity_location() Returns the current entity's immediate location.
object jvmud_entity_location(mixed entity) Returns the supplied entity's immediate location.
void jvmud_destroy_entity(object entity) Destroys an entity and removes it from runtime indexes.

Commands And Interaction Scope

Signature Current behavior
void jvmud_enable_commands() Compatibility entry point for command-capable objects.
void jvmud_add_action(string method) Remembers a mudlib action method for later verb registration.
void jvmud_add_action(string method, string verb) Registers a verb to dispatch to a mudlib action method.
void jvmud_add_verb(string verb) Registers a verb for the most recently remembered action method.

Time, Light, And Compatibility Hooks

Signature Current behavior
int jvmud_time() Returns current Unix-style wall-clock seconds.
int jvmud_set_light(int amount) Updates runtime light state and returns the current light value.
void jvmud_schedule_recurring_tick(int enabled, int interval_seconds) Schedules or cancels recurring temporal work for the current mudlib object.
void jvmud_call_out(string method, int delay) Compatibility placeholder for delayed callback requests.
void jvmud_call_out(string method, int delay, mixed arg) Compatibility placeholder for delayed callback requests with one argument.
int jvmud_remove_call_out(string method) Compatibility placeholder; currently returns -1.

Text, Type, And Collection Utilities

Signature Current behavior
int jvmud_size(mixed value) Returns the size of a string, collection, mapping, or array.
mixed jvmud_read_mudlib_text(string path) Reads a mudlib-relative text file, returning LPC false when unavailable.
string jvmud_lowercase_text(mixed value) Converts text to lowercase.
string jvmud_capitalize_text(mixed value) Capitalizes the first character of text.
status jvmud_is_string(mixed value) Returns LPC true when the value is a string.
status jvmud_is_array(mixed value) Returns LPC true when the value is represented as an array/list.
array allocate(int size) Creates an array initialized with zero values.

Efuns

Efuns are the LPC-facing entry points that let compiled mudlib objects talk to JVMud runtime behavior.

Compatibility Layer

JVMud can expose legacy LPC names while translating them toward engine-native operations: output delivery, current execution context, object calls, movement, inventory traversal, perception, and scheduling.

Design Bias

Efuns should keep current LPC content usable without making old driver concepts the engine's ontology. Compatibility belongs at the boundary.

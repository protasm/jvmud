Compiler surface

Grammar

JVMud's compiler parses LPC through a scanner, preprocessor, Pratt parser, semantic model, typed IR, and JVM bytecode backend.

Current Focus

Grammar work is driven by the LPC subset needed to host real mudlib content. Unsupported syntax should become evidence for focused compiler work rather than a reason to broaden the project into multiple language targets.

Pipeline

Source moves through preprocessing, scanning, parsing, semantic checks, IR lowering, and bytecode generation. The public documentation here will grow alongside those supported slices.

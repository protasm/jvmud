Frequently asked questions

What is a MUD?

A multi-user dungeon: a shared world in which players interact through text. An LPMud uses LPC to define its game objects and behavior.

Is JVMud a game?

JVMud is the compiler and engine. A mudlib defines the game it hosts. The bundled Small Mercies world provides an example; its walkthrough is in the manual.

Do I write game content in Java or LPC?

Mudlib content is written in LPC. Java implements the compiler and engine. See LPC authoring or the Java API.

Can I run an existing LPC mudlib?

Compatibility depends on the language features and driver behavior it uses. Existing mudlibs can require explicit configuration and compatibility shims. See compatibility shims.

Where are the setup instructions?

Use the User Manual. The downloads page lists packages and their requirements.

Where should I report a problem?

Use the GitHub issue tracker. Include the version, relevant configuration, steps to reproduce, and diagnostic output.

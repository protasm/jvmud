Open-source LPC worlds on the JVM

A Java-native engine for building and playing text-only, interactive, multiplayer worlds in the LPMUD tradition: live LPC content hosted inside a JVMud engine built around places, entities, personas, persistence, time, and presence.

Project status

Experimental, with explicit scope

JVMud includes a working compiler, hosted-world layer, Telnet transport, storage adapters, and local admin shell. Legacy compatibility is incremental; production hardening remains ongoing.

Try JVMud locally

Download the macOS or Linux package for your processor, extract it, and use a POSIX terminal to launch Small Mercies, the bundled five-room teaching world. Java is included; Maven is not needed. Then connect a Telnet client to 127.0.0.1:4000.

Choose a guest name, gender, and class. Try help and score. Characters last for one connection.

Play Small Mercies →

scripts/jvmud-start \

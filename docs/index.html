Open-source LPC on the JVM

A modern Java-native platform for building and playing text-only, interactive, multiplayer games in the LPMUD tradition: persistent, temporal, player-present worlds that bring your ideas to life.

What It Is

JVMud compiles LPC-authored objects to JVM classes and hosts them inside an engine built around the core features of MUD: Game, Text-Only, Interactive, Multiplayer, World, Persistence, Temporality, and Presence. Check out the Glossary to learn more!

Current Shape

The repository contains a Java runtime, an LPC compiler, a local admin CLI, a Telnet-capable game server, and a vanilla LPMUD 2.4.5 mudlib used as the compatibility target.

Project Areas

Runtime

Engine-owned world concepts: worlds, places, links, entities, containment, capabilities, and deterministic scheduling.

Compiler

Scanner, preprocessor, parser, semantic analysis, typed IR, bytecode generation, efun contracts, and generated-code helpers.

Interaction

A single-user admin shell for filesystem/object work, plus a separate server path for walking the live mudlib through player-style commands.

Status

JVMud is early-stage engine work. The baseline build is Maven-backed, the compiler can run smoke paths, and the runtime can boot a small interactive session. Compatibility work is deliberately incremental. 

mvn test
./jvmud-admin
./jvmud-start -mudlib-dir mudlibs/lp245

Java API Docs

Generated Javadocs publish the current compiler and engine contracts: runtime world primitives, mudlib boundary declarations, compiler pipeline entry points, LPC runtime loading, and efun registration.

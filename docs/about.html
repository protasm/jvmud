About JVMud

An engine for LPC-authored multiplayer text worlds.

What it does

JVMud compiles LPC source to JVM bytecode and loads it as live objects. It provides the engine, hosted instances, player connections, persistence adapters, and an administration interface.

A mudlib supplies the world’s content, commands, game rules, and presentation. JVMud includes Small Mercies, a small teaching world.

Design

The project separates engine behavior, mudlib execution, transport, and persistence. Each hosted mudlib has its own execution queue and clock. Mudlibs interpret player commands.

The source code is part of the product: it is intended to be read, understood, and extended.

Start with Key Concepts, then see the manual’s design philosophy and architecture for the detailed account.

Status

JVMud is under development. Downloads are preview releases, and compatibility with existing LPC mudlibs is incremental.

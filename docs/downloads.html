Download JVMud

Preview.5 adds optional dynamic typing and removes LP245’s field/local type overrides, fixing the crown valuation bug.

JVMud 0.1.0-preview.7 includes the compiled engine, launchers, and editable LPC source for Small Mercies and LP245. The macOS and Linux packages include Eclipse Temurin Java 21.0.12.1; no separate Java installation is needed.

Requirements

Choose the package matching your operating system and processor. A POSIX terminal and a separate MUD client are needed; Maven is not.

Start your first world

In a terminal, go to the writable folder containing your download. For Apple Silicon, run the commands below; for another platform, replace the archive filename with your download:

mkdir current &&
tar -xzf jvmud-0.1.0-preview.7-macos-aarch64.tar.gz --strip-components=1 -C current &&
cd current &&
scripts/jvmud-start smallmercies

Keep the installation in current across releases. These commands stop if that directory already exists; use the updater below for an existing installation. On EC2, start in a writable /opt/jvmud directory and select the Linux package matching your instance architecture. Your running installation will be /opt/jvmud/current.

Wait for JVMud mudlib listening on, then connect a Telnet-capable MUD client to 127.0.0.1:4000 with SSL/TLS disabled. Choose a guest name, gender, and class. Try help, look, and north. Stop the server with Ctrl+C.

Update an installation

From your existing current directory (on EC2, cd /opt/jvmud/current):

scripts/jvmud-update --check
scripts/jvmud-update

The updater verifies the latest matching download, stops this installation's servers cleanly, and creates a full backup in ../backup/, beside the distribution folder. It updates JVMud and shipped mudlib jvmud/ files, then restarts the servers. Other mudlib content and saved data remain in place. Starting with preview.6, comment-only configuration differences do not block updates, edited Markdown documentation is backed up and replaced, and genuine adapter/configuration conflicts are reported together before downtime. The updater already installed performs each upgrade. External files and databases need separate backups.

The installation folder keeps its name across releases; the updater reports the installed version. Do not rename a running installation. Stop its servers cleanly first, then relaunch them from the new location with their original options and update any external paths. The bundled Java runtime is available through jre; server logs live in each mudlib's jvmud/log/ directory. Players must reconnect after an update. Earlier previews without the updater require a manual migration; see the package README for recovery and migration details.

Run LP245

To start the bundled LP245 world on a separate port:

scripts/jvmud-start --port 4001 lp245

Connect to 127.0.0.1:4001 and follow the character creation prompts. The package retains LP245's LPC source and JVMud compatibility files. Existing player saves and old logs are excluded.

Preview status

All 563 Maven tests passed. Runtime-free packages and the Apple Silicon package passed launcher, formatter, login, movement, and administration checks for both worlds, plus updater backup, restart, and rollback tests. The published preview.6 updater was also tested upgrading to preview.7 in a stable current directory. Intel macOS and Linux packages passed archive and runtime-integrity checks; they were not executed on those platforms for this release. LP245 compatibility remains experimental.

Launchers use the bundled Java runtime by default. Set JVMUD_JAVA_HOME to explicitly select another Java installation.

The package's README covers launch options, administration, and upgrades. RELEASE-STATUS.md records validation and licensing status; no project license has yet been declared for JVMud or Small Mercies.

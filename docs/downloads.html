Download JVMud

JVMud 0.1.0-preview.2 is an experimental end-user distribution. It includes the compiled engine, runtime dependencies, launchers, and editable LPC source for both Small Mercies and LP245.

Download tar.gz · 7.1 MB

SHA-256 checksum

Requirements

Java 21 or newer and a POSIX shell on macOS, Linux, or Windows WSL. Maven is not needed. Java and a MUD client are installed separately.

Start your first world

In a terminal, go to the writable folder containing your download and run:

tar -xzf jvmud-0.1.0-preview.2-bin.tar.gz
cd jvmud-0.1.0-preview.2
scripts/jvmud-start mudlibs/smallmercies/jvmud/smallmercies.config

Wait for JVMud mudlib listening on, then connect a Telnet-capable MUD client to 127.0.0.1:4000 with SSL/TLS disabled. Choose a guest name, gender, and class. Try help, look, and north. Stop the server with Ctrl+C.

Run LP245

To start the bundled LP245 world on a separate port:

scripts/jvmud-start --port 4001 mudlibs/lp245/jvmud/lp245.config

Connect to 127.0.0.1:4001 and follow the character creation prompts. The package retains LP245's LPC source and JVMud compatibility files. Existing player saves and old logs are excluded.

Preview status

This update fixes the missing quicktyper in LP245’s storage room. The gameplay check now obtains the tool and uses an alias.

All 541 Maven tests passed. Both extracted mudlibs passed login, movement, and administration checks on macOS with OpenJDK 25. JVMud targets Java 21; Java 21 itself, Linux, and Windows WSL have not yet been validated for this preview. LP245 compatibility remains experimental.

The package's README covers launch options, administration, and upgrades. RELEASE-STATUS.md records validation and licensing status; no project license has yet been declared for JVMud or Small Mercies.

Installation and updates

A POSIX terminal and a Telnet-capable MUD client are needed. Follow the installation instructions in the User Manual. Release-specific launch, update, and recovery instructions are also included in each package’s README.

These are preview packages. Platform validation and licensing details are recorded in the included RELEASE-STATUS.md.
